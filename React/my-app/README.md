# SkillMatch Web

React 19 and Vite frontend for SkillMatch. The application provides authentication,
resume and job management, explainable match results, career analytics, curated
learning recommendations, and an accessible CSS 3D workspace.

## Development

```powershell
npm install
npm run dev
```

The frontend uses `http://localhost:5095/api` by default. Override it with
`VITE_API_URL` when the API runs elsewhere.

## Validation

```powershell
npm run lint
npm run build
```

See the repository-level `README.md` for complete setup, architecture, API, testing,
and container instructions.
